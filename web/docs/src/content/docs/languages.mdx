## Querying the live registry

The authoritative source is the running API:

```bash
curl http://localhost:8080/v1/languages \
  | jq '.[] | {id, name, version, default_limits}'
```

Each entry includes `default_limits` — the server's per-language ceilings
for `memory_mb` / `cpu_time` / `wall_time` / `max_pids`. Submissions that
omit limits get these defaults; submissions that exceed them are rejected at
validation time.

## Source of truth in the repo

The registry config lives at [`runners/languages.toml`](https://github.com/bhadri01/ZeroCode/blob/main/runners/languages.toml).
A typical entry:

```toml
# Interpreted (no compile step):
[[language]]
id = 71
name = "Python"
version = "3.13"
source_file = "main.py"          # written to /box/ before the run
compile_cmd = []                  # empty = interpreted
run_cmd = ["/usr/bin/python3.13", "main.py"]
env = [["PYTHONUNBUFFERED", "1"]]

# Compiled (compile-then-run in one sandbox; run_cmd executes ./prog):
[[language]]
id = 73
name = "Rust"
version = "1.x-latest"
source_file = "main.rs"
compile_cmd = ["/usr/local/cargo/bin/rustc", "-O", "-C", "panic=abort", "main.rs", "-o", "prog"]
run_cmd = ["./prog"]
# Optional per-language overrides (else the API global default applies):
default_limits = { cpu_time = 10.0, wall_time = 20.0, memory_mb = 512, max_pids = 96, max_stdout = 65536, max_stderr = 65536, enable_network = false }
```

Adding a language is a `runners/languages.toml` entry + a runner image with
the toolchain installed + (for compiled languages) a compile-phase spec
that produces `/box/prog`. Compile errors surface via the dedicated
`compile_output` pipe and the `compile_error` status kind.

<Aside type="tip">
  NativeSandbox applies `default_limits` to **both** the compile and run
  phases, so compile-heavy languages (JVM, .NET, Haskell, Swift, Crystal)
  set generous `default_limits` rather than relying on the small global
  default. `${memory_mb}`, `${cpu_time}`, `${wall_time}`, `${max_pids}`, and
  `${jvm_heap_mb}` placeholders in `env` values are substituted per
  submission.
</Aside>

## Adding more languages

New languages come with a `tests/edge_cases/<lang>.rs` hello-world test so we
don't regress, and (where natural) a playground starter. Each language adds
runner-image weight and toolchain attack surface, so proposals start with an
issue describing the use case. The expansion plan lives in
[`docs/ROADMAP.md`](https://github.com/bhadri01/ZeroCode/blob/main/docs/ROADMAP.md).
