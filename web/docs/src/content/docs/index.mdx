ZeroCode is an open-source code execution sandbox written in Rust. Eight
kernel-enforced isolation layers, seven language runtimes (Python, Node,
Rust, Go, C, C++, Java), sub-5 ms dispatch via Postgres LISTEN/NOTIFY, and
a Judge0-compatible REST API plus gRPC.

## Where to start

- **[Quickstart](/docs/quickstart)** — clone, `docker compose up`, submit your first program in 60 seconds.
- **[REST API reference](/docs/api)** — endpoints, request/response shapes, error semantics.

## At a glance

| | |
|---|---|
| **Isolation layers** | 8 (userns · ns · pivot\_root · landlock · seccomp BPF · cgroup v2 · capdrop · NO\_NEW\_PRIVS) |
