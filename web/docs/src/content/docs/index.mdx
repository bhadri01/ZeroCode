ZeroCode is an open-source code execution sandbox written in Rust. Eight
kernel-enforced isolation layers, 41 language runtimes (the Core 7 — Python,
Node, Rust, Go, C, C++, Java — plus 34 more across Batches A–G), sub-5 ms
dispatch via Postgres LISTEN/NOTIFY, and
a clean REST API with Server-Sent Events for live output. Submit one
program against up to 100 test cases in a single batch request, and run
it unauthenticated — ZeroCode is an open backend you protect at the
network layer.

## At a glance

| | |
|---|---|
| **Isolation layers** | 8 (userns · ns · pivot\_root · landlock · seccomp BPF · cgroup v2 · capdrop · NO\_NEW\_PRIVS) |
| **Language runtimes** | 7 (Python · Node.js · Rust · Go · C · C++ · Java) |
| **Dispatch latency** | < 5 ms p99 (LISTEN/NOTIFY, no polling) |
| **Streaming** | SSE for live stdout/stderr (`GET /v1/submissions/{token}/stream`) |
| **Batch test cases** | 1 program × up to 100 stdin cases per request (`POST /v1/submissions/batch`) |
| **Auth** | none — open backend; restrict at the network layer |
| **Known CVEs** | 0 |
